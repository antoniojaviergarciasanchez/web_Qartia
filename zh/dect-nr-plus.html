什么是 DECT NR+

工业专网

一种专为 IoT、语音、视频和低延迟服务准备的私有分布式无线电技术。

DECT NR+ 是一种非蜂窝 5G 技术，当项目需要自己的专用网络、稳定并准备好运行而不依赖于传统的蜂窝架构时，该技术特别有趣。

其分布式方法可以轻松部署传感器、遥测、执行器和现场服务，其架构可以分阶段增长、适应操作环境并维护更轻量级的部署逻辑。

但其值不限于IoT。 DECT NR+ 还可以传输语音、流视频和 IP 服务，其中非常低的延迟与高信息传输相结合，这在视频、语音和远程操作应用程序中特别有用。

对于 Qartia 来说，DECT NR+ 特别适合工业、环境、农业和民用基础设施、音频/视频应用以及 IP 服务，其中无线电鲁棒性、部署自主性、数据连续性和支持实时服务的能力决定了决策的质量。

本页总结了其主要功能、协议栈以及它在 5G 专用网络策略中提供最大价值的场景类型。

DECT NR+ 在不断发展的生态系统中将标准化、认证、学术界、欧洲项目和工业实施结合起来。

问题

为什么经典的蜂窝网络并不总是适合。

过度依赖操作员

许多项目在网络的部署、演进和管理方面需要更多的自主权。

调试复杂性

对核心、SIM 和较重架构的需求可能会减慢小型或分布式部署的速度。

现场覆盖困难

工业、农村或远程基础设施环境需要更灵活和适应性更强的拓扑。

分阶段缩放

并非所有项目都以大型网络开始；很多时候以模块化的方式进行增长是很方便的。

延迟和可靠性

在某些情况下，网络不仅必须覆盖，而且必须保持连续性和受控的响应时间。

服务共存

在许多项目中，同一网络必须支持遥测、报警、语音、流音频、视频和其他具有不同要求的IP服务。

关键能力

不需要核心网络或SIM卡，降低了复杂性和外部依赖性。

灵活的 PHY/MAC

强大的物理层

有序无线电接入

减少手动规划

不仅仅是感官

同一网络可用于遥测、报警、语音、流音频、视频和其他具有苛刻需求的 IP 服务，远远超出了传统的 IoT 网络。
