# Qartia Web Corporativa

Sitio web corporativo local de Qartia Smart Technologies, preparado en HTML estatico para su edicion y publicacion.

## Contenido

- Portada corporativa
- Paginas de productos
- Paginas de servicios
- Noticias y casos de uso
- Seccion industrial con casos de monitorizacion de activos criticos y mantenimiento predictivo
